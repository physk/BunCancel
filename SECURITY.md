# Security and privacy

BunCancel's design goal is entirely local signal processing, with no telemetry, cloud account, recording upload or default session recording.

Please report security flaws in plugin lifecycle, endpoint capture, shared memory, device routing or packaged binaries privately through GitHub's private vulnerability reporting where enabled. Do not publish account credentials, identifiable call recordings or access tokens in an issue.

A debug build must not save raw microphones or reference feeds without explicit user action, clear file location, retention controls and consent. There are no release artifacts or security guarantees yet.
